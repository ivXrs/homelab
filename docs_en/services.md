## Overview

These are the services currently running in the lab:

| Name | Description |
|---|---|
| [Tailscale](https://tailscale.com/) | Private remote access network (WireGuard-based mesh VPN) to connect to the homelab from outside the house |
| [Pi-hole](https://pi-hole.net/) | Local DNS server that blocks ads and trackers at the network level |
| [Nginx Proxy Manager](https://nginxproxymanager.com/) | Reverse proxy with a web interface to manage domains, subdomains, and SSL certificates for internal services |
| [Vaultwarden](https://github.com/dani-garcia/vaultwarden) | Self-hosted password manager, compatible with the official Bitwarden clients |
