## Resumen

Estos son los servicios que corren actualmente en el laboratorio:

| Nombre | Descripción |
|---|---|
| [Tailscale](https://tailscale.com/) | Red privada de acceso remoto (VPN en malla basada en WireGuard) para conectarse al homelab desde fuera de casa |
| [Pi-hole](https://pi-hole.net/) | Servidor DNS local que bloquea anuncios y rastreadores a nivel de red |
| [Nginx Proxy Manager](https://nginxproxymanager.com/) | Proxy inverso con interfaz web para gestionar dominios, subdominios y certificados SSL de los servicios internos |
| [Vaultwarden](https://github.com/dani-garcia/vaultwarden) | Gestor de contraseñas autoalojado, compatible con los clientes oficiales de Bitwarden |
